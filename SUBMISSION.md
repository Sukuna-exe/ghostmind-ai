# Hackathon Submission Pack

## One-line pitch

**GHOSTMIND is an adaptive AI story game where the world remembers what you do.**

## 60-second description

GHOSTMIND combines generative AI with an interactive game world. Players communicate with NOVA, an AI companion that remembers decisions and uses persistent state to influence future dialogue, quests and story direction. Instead of only chatting with an AI, players must physically interact with locations in the facility to progress. Their choices create one of three story paths — Truth, Trust or Escape — leading to different endings.

## Demo script

### 0:00–0:15 — Hook

“Most AI game demos generate dialogue. GHOSTMIND goes one step further: the AI changes the actual game state.”

Show the landing page and enter the world.

### 0:15–0:45 — Adaptive dialogue

Choose a meaningful dialogue option. Show NOVA responding and the player stats changing.

### 0:45–1:15 — AI quest

Show the generated active objective and its target location.

Click the wrong location first and show that the game rejects it.

Then use the correct interaction.

### 1:15–1:45 — Persistent memory

Show the completed quest, reward and memory fragment. Point out that the state is persisted server-side.

### 1:45–2:15 — Branching

Show the story path changing based on player decisions.

### 2:15–2:45 — Ending

Complete the campaign and reveal the ending.

Finish with:

“GHOSTMIND isn't just generating a story. It's remembering the player who created it.”

## Judge-facing highlights

### Usefulness / Impact

Demonstrates a practical pattern for adaptive AI game experiences where generated content is connected to persistent state and gameplay actions.

### Originality

AI is used as a stateful narrative system, not simply as a chatbot.

### Technical execution

Structured AI output, persistent memory, server-side API integration, quest validation and branching story state.

### Product experience

Three-column command-center UI, world locations, active objectives, progress, memory fragments and explicit campaign endings.
